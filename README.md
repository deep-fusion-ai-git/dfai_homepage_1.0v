# DeepFusion AI — Website v3

DFAI 공식 웹사이트 v3 프로토타입.

## 페이지 구성
- `index.html` — Home (Hero, Impact, What We Do, Applications, Trusted By, Recognition, Contact CTA)
- `about.html` — About (Our Story, Vision, Team, Milestones, Recognition, Company Info)
- `technology.html` — Technology (7 Core Technologies)
- `solutions.html` — Solutions (USV, UGV, Wave Detection, Autonomous Driving)
- `contact.html` — Contact (Inquiry, Form, Office Locations, FAQ)

## 기술 스택
- Vanilla HTML / CSS / JavaScript
- 외부 라이브러리 없음
- 다크 Ocean Blue 테마, 반응형 (1024 / 768 / 480px)

## 로컬 실행
```bash
python3 -m http.server 8000
# http://localhost:8000
```
